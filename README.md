# Portfólio - Eugenio Santana

Bem-vindo ao repositório do meu portfólio web! Este projeto foi criado para apresentar minhas habilidades, projetos e foco profissional na área de  **Desenvolvimento Full-Stack**.

## 🌟 O que tem de legal neste projeto?

Este site não é apenas um currículo estático, ele possui várias interações para mostrar conhecimento prático em programação front-end:

- **Interface Responsiva:** Funciona perfeitamente em telas de computador e também em celulares.
- **Modo "Red Team" (Hacker Mode):** Um botão interativo especial em formato de caveira que transforma todo o visual do site, ativando uma chuva de códigos binários (estilo Matrix) e mudando as descrições profissionais.
- **Efeito Máquina de Escrever (Typewriter):** Textos que parecem estar sendo digitados em tempo real na tela inicial.
- **Carrossel de Habilidades:** Duas esteiras rolantes que mostram as ferramentas e linguagens que domino.
- **Otimização de Performance:** Uso de observadores de tela (`IntersectionObserver`) para carregar animações apenas quando o usuário chega na seção correta.

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido do zero (sem uso de frameworks pesados de interface), focando em velocidade e controle total do código:

- **HTML5:** Estrutura do conteúdo do site.
- **CSS3:** Estilização visual, cores, botões e animações CSS.
- **JavaScript (Vanilla JS):** Toda a inteligência da página, desde o menu no celular até a ativação do modo hacker.
- **Canvas API (HTML5):** Usado em conjunto com JavaScript para desenhar e animar os códigos verdes e vermelhos caindo na tela.

## 🚀 Como abrir o projeto no seu computador

É muito simples! Como o projeto roda diretamente no navegador, você não precisa instalar nada (nem Node.js, nem Python, etc.).

1. Faça o download desta pasta para o seu computador.
2. Encontre o arquivo HTML principal (exemplo: `v3-logo-terminal.html` ou `index.html`).
3. Dê **dois cliques** no arquivo.
4. O portfólio abrirá instantaneamente no seu navegador padrão (Chrome, Edge, Firefox, etc.).
